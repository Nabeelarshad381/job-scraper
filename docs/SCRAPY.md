## 🎯 Overview

The Scrapy spider processes URLs generated by Phase 1 (Selenium) and extracts 9 required data fields from each job posting. It implements professional data cleaning, validation, and CSV export.

## 📊 9 Required Data Fields

```
1. job_title        - Position name
2. company_name     - Hiring company
3. location         - Location with [REMOTE]/[HYBRID]/[ON-SITE] tags
4. department       - Team/Department name
5. employment_type  - Full-time, Part-time, Contract, Internship
6. posted_date      - Publication/Posted date
7. job_url          - Direct link to job posting
8. job_description  - Full job description text
9. required_skills  - Pipe-separated skill list
```

## 🔄 Complete Data Flow

```
CSV from Phase 1 (job_links.csv)
    ↓
Spider loads URLs
    ↓
For each URL:
  - Make HTTP request
  - Parse HTML/DOM
  - Extract 9 fields
  - ItemLoader for processing
    ↓
Pipeline 1: AshbyPipeline
  - Clean whitespace
  - Normalize fields
  - Validate data
    ↓
Pipeline 2: CSVExportPipeline
  - Convert skills to pipe-format
  - Write to CSV file
    ↓
Output: jobs.csv (Final Dataset)
```

## 📋 Field Extraction Strategy

### 1. Job Title Extraction

**Selectors tried (in order):**
```python
h1::text                           # Standard h1 tag
h1 //text()                        # All text in h1
[data-testid="job-title"]::text   # Data attribute
```

### 2. Company Name Extraction

```python
h2::text                           # Typically in h2
//a[contains(@href, "ashby")]/text()  # Link to company
'Ashby Demo Org'                   # Default fallback
```

### 3. Location with Tag

**Extraction:**
```python
[class*="location"]::text
//text()[contains(., "Remote")]
```

**Tagging logic:**
```python
if 'remote' in location.lower():
    location_tagged = f"{location} [REMOTE]"
elif 'hybrid' in location.lower():
    location_tagged = f"{location} [HYBRID]"
else:
    location_tagged = f"{location} [ON-SITE]"
```

**Examples:**
- Input: "San Francisco, CA" → Output: "San Francisco, CA [ON-SITE]"
- Input: "Remote - USA" → Output: "Remote - USA [REMOTE]"
- Input: "New York (Hybrid)" → Output: "New York (Hybrid) [HYBRID]"

### 4. Department Extraction

```python
[class*="department"]::text
//strong[contains(text(), "Department")]/following-sibling::text()
//dt[contains(text(), "Department")]/following-sibling::dd/text()
```

### 5. Employment Type

```python
[class*="employment"]::text
//text()[contains(., "Full-time")]
// Match: Full-time, Part-time, Contract, Intern
```

### 6. Posted Date

```python
[class*="date"]::text
//text()[contains(., "Posted")]
// Match: "Posted 3 days ago", "March 15", "2026"
```

### 7. Job Description

**Combined extraction:**
```python
description_parts = response.css('[class*="description"]::text').getall()
description_parts += response.xpath('//div[@class="job-description"]//text()').getall()
job_description = ' '.join([text.strip() for text in description_parts])
```

### 8. Skill Extraction

**Method 1: Bullet pointsfrom DOM**
```python
skill_items = response.css('li::text').getall()
# Filter items: length 3-100 characters
```

**Method 2: Pattern matching**
```python
COMMON_SKILLS = [
    'Python', 'Java', 'JavaScript',
    'React', 'Django', 'FastAPI',
    'SQL', 'MongoDB', 'AWS', 'Docker',
    'Machine Learning', 'TensorFlow',
    # ... full list of 50+ skills
]

for skill in COMMON_SKILLS:
    if skill.lower() in job_description.lower():
        extracted_skills.append(skill)
```

**Output format:** Pipe-separated
```
Python|JavaScript|React|SQL|AWS|Docker
```

## 📤 Data Cleaning Pipeline

**AshbyPipeline** processes each item:

```python
def process_item(self, item, spider):
    adapter = ItemAdapter(item)
    
    # 1. Clean whitespace
    for field in adapter.field_names():
        if isinstance(adapter[field], str):
            adapter[field] = adapter[field].strip()
    
    # 2. Ensure skills is list
    if isinstance(adapter['required_skills'], str):
        adapter['required_skills'] = adapter['required_skills'].split(',')
    
    # 3. Add timestamp
    adapter['extracted_timestamp'] = datetime.now().isoformat()
    
    return item
```

## 🚀 Performance Optimization

**Current settings:**
- Sequential requests (CONCURRENT_REQUESTS = 1)
- 2-second delay per request
- Estimated: 5-15 minutes for 100-500 jobs

**To speed up (reduce delay):**
